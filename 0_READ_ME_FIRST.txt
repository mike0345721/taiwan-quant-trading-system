TAIWAN STOCK DECISION DASHBOARD V3.6.5 - WINDOWS QUICK START

FIRST USE OR PASSWORD RESET
1. Close the black dashboard window if it is running.
2. Double-click 1_SETUP.bat
3. Enter the same password twice. At least 12 characters.
   Chinese and special characters are supported.
4. The setup will display: Password self-check: PASSED
5. Double-click OPEN_DASHBOARD.bat
6. Open http://127.0.0.1:8787
7. There is no username. Enter only your password.

PASSWORD TROUBLESHOOTING
- Double-click 3_CHECK_PASSWORD.bat to verify the saved password.
- Double-click 4_RESET_PASSWORD.bat to replace the password.
- After five failed attempts, close 2_START.bat and start it again.

AUTOMATIC START AND UPDATE
- Double-click 10_INSTALL_AUTO_START.bat once.
- It creates a desktop shortcut and starts the dashboard after Windows sign-in.
- Official data updates Monday-Friday at 08:30.
- Use 11_REMOVE_AUTO_START.bat to remove both automations.
- 2_START.bat remains available only for troubleshooting.

IMPORTANT
- The dashboard listens only on this computer.
- The dashboard uses live data and has no broker credentials or trading permissions.
