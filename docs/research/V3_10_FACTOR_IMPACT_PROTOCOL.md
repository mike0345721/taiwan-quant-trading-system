# V3.10 第一輪盤中因子影響研究協議

> 凍結日期：2026-07-29  
> 狀態：research-only  
> 本協議只研究既有資料，不調整正式權重、不新增交易能力。

## 研究問題

在同一組通過稽核的TX日盤資料中，盤後已知的法人、OI、選擇權結構、IV及基差因子，
是否能在既有價格基準之外，改善下一交易日09:00後30／60／120分鐘方向或波動幅度的
樣本外描述能力？

## 不研究

- 不研究即時下單、部位管理或自動交易。
- 不把公開OI推估稱為真實Dealer部位或成本。
- 不使用精確CVD、即時Greeks或尚未通過資料閘門的欄位。
- 不最佳化策略停損、目標、持有時間或因子權重。
- 不因看到結果而更換本輪因子、錨點、切分或判定規則。

## 決策錨點與時間口徑

- 每個交易日只取一個09:00 Asia/Taipei錨點。
- 錨點必須等5分鐘K的barIndex 2完整收盤。
- 當日價格基準只使用09:00以前完成的K棒。
- 法人、OI、Max Pain、Wall、IV、Skew、基差及期限結構一律只使用
  `factorSourceDate < tradeDate`的盤後資料。
- 選擇權契約必須在研究日仍未到期，選擇最近可用到期別，不把已到期契約帶到下一日。
- 未知值維持`null`，不補0、不前後填補。

## 固定價格基準

1. 開盤至09:00報酬
2. 前15分鐘區間寬度
3. 09:00收盤相對5分鐘OHLCV近似VWAP
4. 前15分鐘累積成交量的`log1p`

## 第一輪因子

| 群組 | 因子 |
|---|---|
| 日內量能 | 09:00同時段20日RVOL |
| 期貨部位 | 外資期貨淨部位1日變化／近月OI、近月市場OI變化率 |
| 選擇權結構 | Max Pain距前日TX收盤、Call／Put Wall距離不對稱 |
| 波動 | 最近可用到期ATM IV、25D Skew |
| 基差期限 | 期現貨收盤基差bps、近次月價差bps |

同一模型一次只增加一個因子；同群因子不得累加成信心分數。

## 研究目標

每個錨點保存：

- 未來30／60／120分鐘收盤報酬
- 未來30／60／120分鐘最大絕對路徑幅度，定義為`max(MFE, abs(MAE))`

## 固定驗證

- 最後20%日期為歷史保留期。
- 前80%使用至少60日訓練、12日測試的擴展式Walk-Forward。
- 固定Ridge lambda = 1。
- 基準與候選必須使用完全相同日期。
- 歷史保留期誤差改善使用5日移動區塊Bootstrap，共2,000次。
- 同一目標家族使用Holm修正，alpha = 0.05。
- 歷史保留期執行後即視為已檢視，不得再稱為全新證據。

## 判決

- `direction_candidate_for_forward_validation`
- `risk_filter_candidate_for_forward_validation`
- `descriptive_observation_only`
- `not_supported_or_unstable`
- `insufficient_holdout`

任何候選都只能進入全新前向驗證，正式權重保持0。未通過因子保留結果，不回頭調參。

## 失效與限制

- 135日仍只涵蓋有限市場循環。
- 5分鐘K的VWAP是OHLCV近似值，不是逐筆精確VWAP。
- 多個期限目標與相鄰交易日仍有時間相依，因此使用日期級切分與區塊Bootstrap。
- 選擇權IV是盤後Black-76推算值，不是即時供應商Greeks。
- 即使統計改善，也可能只反映2026年特定Regime，必須等待真正新增資料。
