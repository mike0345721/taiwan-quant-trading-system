# 驗證清單

## 每次一般修改

- [ ] 確認沒有修改或提交`.env`、憑證、Token及密碼。
- [ ] 依實際變更範圍選擇必要測試、資料稽核與秘密掃描，不無差別執行無關流程。
- [ ] 若修改啟動、部署或服務行為，確認V1仍可由`2_START.bat`啟動。
- [ ] 只有實際功能或行為改變時才更新`CHANGELOG.md`。
- [ ] 只有真實現況改變時才更新`CURRENT_STATUS.md`。
- [ ] 只有使用者授權的CURRENT／NEXT／FUTURE變更才更新`ROADMAP.md`。
- [ ] 只有重要且長期有效的新決策才更新`DECISIONS.md`。

## 資料來源驗證

- [ ] 每個來源保存資料日與抓取時間。
- [ ] 休市日不把前一交易日誤標成今日。
- [ ] API失敗時標示快取與錯誤，不靜默沿用。
- [ ] 數值缺失不轉成0。
- [ ] 日盤、夜盤及交易日期定義一致。
- [ ] 週選、月選與不同到期契約不混加。
- [ ] 結算日與換月資料另行標示。
