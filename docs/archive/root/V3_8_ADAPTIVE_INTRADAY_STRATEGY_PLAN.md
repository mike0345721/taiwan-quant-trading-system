# V3.8 自適應盤中策略研究計畫

日期：2026-07-18  
狀態：已立項，尚未啟動模擬委託或實單  
安全邊界：只讀研究、`executionAuthorized=false`

## 共同願景

我們期待找到能辨識多空方向、扣除成本後維持正期望值的策略，但不把「聖杯」定義成永遠正確的單一指標。

本專案對聖杯的可驗證定義是：

> 在不同市場狀態下，自動選擇適用的凍結策略；沒有足夠優勢時不交易；有優勢時控制曝險；策略失效時能被監控、降級與停用。

一筆交易可能由運氣決定，長期結果必須由可重複的淨期望值、風險控制及一致執行證明。

## 第一性原則

1. 價格直接決定損益，是盤中進出場的主要依據。
2. 成交量、主動成交與未平倉量負責確認參與程度，不單獨代表方向。
3. 法人、選擇權、總體與跨市場資料只建立環境、風險及禁止交易條件。
4. 淨期望值必須扣除手續費、交易稅、滑價與轉倉成本。
5. 風控不能把負期望策略變成正期望策略；它負責限制破產、尾端虧損及執行偏差。
6. 找不到樣本外優勢時，正確輸出是「不交易」，不是繼續調參直到回測漂亮。

## 不做的事

- 不宣稱能精確預測下一根K棒或每日最高、最低點。
- 不以勝率單獨判定策略好壞。
- 不讓正式策略在盤中自行改參數。
- 不把同一群高度相關因子重複加分。
- 不用未來資料、日後修訂值或缺值補0。
- 本階段不保存券商憑證、不送出委託、不開放自動下單。

## 系統分層

```text
資料品質閘門
    ↓
市場狀態辨識：趨勢／震盪／高波動事件／低流動性
    ↓
交易機會：突破／順勢回踩／假突破反轉／不交易
    ↓
風險與執行：停損、目標、預期R、成本、滑價、部位上限
    ↓
追加式決策與模擬帳本
    ↓
樣本外、Walk-forward及前向驗證
```

### 1. 市場狀態模型

只回答現在適合哪一類策略，不直接下多空結論：

- 趨勢盤：允許突破及順勢回踩。
- 震盪盤：禁止追價，研究假突破與VWAP均值回歸。
- 高波動事件盤：縮小曝險或完全不交易。
- 低流動性／資料異常：禁止交易。

### 2. 交易機會模型

第一輪只預註冊三個簡單、可解釋的策略家族：

1. 開盤15分鐘區間突破。
2. VWAP同向回踩後續走。
3. 開盤區間假突破後回到VWAP方向。

多方與空方分開統計，不假設兩邊效果對稱。每個策略都保留價格-only基準，之後才逐層加入量能與籌碼過濾。

### 3. 預測目標

不只預測下一根漲跌，主要研究：

- 30／60／120分鐘內，先到`+1.5R`或先到`-1R`。
- 扣除成本後的每筆淨期望值。
- 最大順向波動MFE與最大逆向波動MAE。
- 突破後延續或失敗的條件機率。
- 趨勢、震盪、高波動與不交易狀態。
- 最適合的持有時間與逾時退出條件。

`1.5R`只作第一版固定研究門檻；不能因結果不漂亮而在同一測試資料反覆修改。

### 4. 因子加入順序

依下列順序逐群加入，每次必須與相同日期、相同交易機會的前一層配對比較：

1. 價格：K棒、VWAP、開盤區間、夜盤高低、前日高低、ATR。
2. 一般量能：同時段相對成交量、突破量、成交速度及大量成交後的價格反應。
3. 盤中微結構：取得可信Tick方向後研究30秒／1分鐘Delta、日夜盤CVD、價格背離、吸收候選、距離加權五檔失衡、補單速度及流動性恢復。
4. 波動：實現波動、臺指VIX、美國VIX、ATM IV、Skew。
5. 籌碼：前一日已公布的外資期貨、現貨法人、市場OI、基差及選擇權牆位。
6. 跨市場：當時已知的Nasdaq、SOX、匯率與事件風險。

新增因子若沒有改善樣本外淨期望、回撤或尾端MAE，就維持權重0。

## 盤中動能改革規格

- 原始資料以事件為單位保存Tick與BidAsk，再彙整成1秒、5秒、30秒與1分鐘；不得只保留5秒快照。
- `tick_type`必須先與券商文件及樣本成交逐筆核對；未知方向不得硬分成買或賣。
- CVD依日盤、夜盤及合約分開重置，試撮、換月與資料中斷必須標記。
- 五檔失衡使用價格距離加權並要求持續時間；單次委買／委賣總量只顯示，不下方向結論。
- 掛單變化最多標示撤單型風險或補單行為，沒有Order ID時不得宣稱Spoofing。
- 盤中OI不列觸發條件；目前只使用已完成盤後OI作下一交易時段環境。
- 原始「點數÷主動成交量」不採用；價格反應效率須依波動、深度與同時段歷史標準化。
- 微結構特徵優先研究突破確認、吸收、禁止追價及滑價改善，不單獨產生下單指令。

## 自適應的正確方式

自適應不是每天重新最佳化參數。第一版採用「凍結策略庫＋狀態選擇器」：

- 每個策略規則與版本固定。
- 狀態模型只根據當時可取得資料選擇策略或不交易。
- 參數只在預定的離線研究週期更新，使用滾動Walk-forward重新驗證。
- 正式策略與挑戰者策略並行記錄；挑戰者通過門檻後仍需人工核准升級。
- 發現資料漂移、成本上升或近期績效超出容許區間時，自動降級為觀察或停用，不自動放寬規則。

## 研究與升級門檻

### 資料閘門

- 先完成最近30個完整交易日，供工程、圖表與逐根重播驗收。
- 正式盤中研究至少累積120個完整交易日；不足時只能標示初步結果。
- 日夜盤、交易日、主力合約與換月必須正確。
- 與官方日OHLC及未來券商畫面抽樣比對至少100根K棒。
- 缺值不得補0；延遲超過10分鐘時停用價格確認。
- 每個欄位保存`available_at`、`retrieved_at`、來源及資料品質。

### 候選策略閘門

- 訓練、驗證、最終留出與前向資料完全分離。
- Walk-forward各階段不得使用未來資料選參數或市場狀態。
- 報告勝率、平均盈虧、淨期望值、PF、最大回撤、MAE／MFE及交易次數。
- 成本後淨期望值在樣本外為正，且不是由少數極端獲利主導。
- 使用兩倍預估滑價壓力測試後，不得出現明顯結構性失效。
- 多方、空方、日盤、夜盤及市場狀態分開報告。
- 正向、反向、無效、樣本不足及失敗結果全部保留。

### 前向紙上交易閘門

- 先累積至少30個交易日及60至100個獨立候選訊號。
- 規則凍結期間不得回頭修改舊訊號。
- 模擬績效扣除實際券商費率、交易稅與觀察到的滑價。
- 每筆保留觸發、失效、預計R、實際成交假設、未進場原因及資料品質。
- 前向淨期望值未通過時，策略退回研究；不得因單次大賺直接升級。

## 現階段明確禁止

- 券商實單委託與自動下單。
- 保存券商密碼、憑證或下單Token。
- 盤中即時重訓、回頭修改舊訊號或自動提高風險。
- 以一次猜中行情、單一月份或漂亮勝率宣稱找到聖杯。

## 將來需要使用者決定，但現在不阻塞

1. 主要測試日盤、夜盤或兩者分開。
2. 實際交易商品TX、MTX或TMF及券商書面費率。
3. 可接受的單筆風險、每日停止線及最大回撤。
4. 是否在通過前向驗證後進入模擬帳號階段。

在這些決策出現前，全部績效先以`R`與多種成本情境表示，不以真實資金承諾獲利。
