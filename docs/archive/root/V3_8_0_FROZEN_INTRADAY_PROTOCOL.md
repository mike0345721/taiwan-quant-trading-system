# V3.8.0 凍結盤中研究協議

日期：2026-07-18  
狀態：工程協議已凍結；正式策略研究尚未達樣本門檻  
安全邊界：歷史回放與紙上研究，`executionAuthorized=false`

## 目的

本協議用來建立價格-only與一般量能的共同基準。29個交易日只允許工程驗收與描述統計；至少累積120個完整交易日後，才可執行正式訓練、驗證與封存留出研究。

## 固定資料口徑

- 商品：TX主力日盤；日盤、夜盤與不同合約分開，禁止跨合約連線。
- K棒：期交所官方逐筆成交彙整的5分鐘OHLCV；13:45收盤成交併入13:40棒，05:00收盤成交併入04:55棒。
- VWAP：以每根K棒典型價`(H+L+C)/3 × volume`累積的近似值，版本固定標為`bar_typical_price_vwap_v1`；不是逐筆或券商即時VWAP。
- RVOL：只與目標日前20個交易日同一時間棒的成交量中位數比較；`sampleDays < 20`時保持缺值，不補0，也不可稱為20日RVOL。
- 成交量：官方逐筆單式非鉅額口徑；不得要求等於另含價差與鉅額交易的官方日成交量。
- 每列保留交易日、時段、合約、時間、來源、品質、換月旗標及實際可用時間。

## 三個預註冊策略家族

所有訊號都在完整5分鐘K收盤後成立，最早只能用下一根K的開盤價作成交假設。多方與空方分開；每個「策略×方向」同時只能有一筆未結束事件。

### 1. 開盤15分鐘區間突破

- 開盤區間使用08:45、08:50、08:55三根完整K的最高與最低。
- 多方候選：後續完整K收盤價嚴格高於區間上緣；初始停損取訊號K低點與區間上緣的較低者。
- 空方候選：後續完整K收盤價嚴格低於區間下緣；初始停損取訊號K高點與區間下緣的較高者。
- 進場價到停損距離必須大於0，否則記錄為取消，不生成結果。

### 2. VWAP同向回踩續走

- 必須先出現已完成的同方向開盤區間突破。
- 多方候選：近似VWAP斜率為正，回踩K最低價觸及或低於VWAP，但收盤重新站上VWAP；停損為回踩K低點。
- 空方候選：近似VWAP斜率為負，回踩K最高價觸及或高於VWAP，但收盤重新跌回VWAP；停損為回踩K高點。
- VWAP斜率只使用當時及過去K棒，不得使用日終斜率。

### 3. 開盤區間假突破回歸

- 假突破觀察窗固定為突破後3根完整K。
- 空方候選：價格曾向上突破區間上緣，3根內有K收盤回到區間內；停損為該次向上突破期間最高價。
- 多方候選：價格曾向下跌破區間下緣，3根內有K收盤回到區間內；停損為該次向下突破期間最低價。
- 超過3根才回區間不追認為同一事件。

## 固定結果定義

- 風險單位：`1R = |假設進場價 − 初始停損價|`。
- 目標：`+1.5R`；停損：`-1R`。本版不得因結果不漂亮而修改。
- 持有上限：30、60、120分鐘分開產生結果；資料不足以走完整個期限時該結果保持缺值。
- 若同一根K同時觸及目標與停損，採保守順序：先停損。
- 到期未觸及目標或停損，以該期限最後一根完整K收盤退出。
- 每個期限另保存由進場價計算的路徑最高／最低、MFE與MAE；沒有順向或逆向波動時以0表示，不得反號。
- 禁止跨日夜時段、跨合約、跨研究切割區間；重疊候選只保留最早一筆，其餘記錄未進場原因。
- 成本情境固定為來回4、8、16點，8點為相容基準、16點為壓力測試；同時報gross與net，不挑最好成本。

## 因子加入順序

1. `price_only`：價格、開盤區間、近似VWAP、前日／夜盤價位、過去式波動。
2. `price_plus_general_volume`：在完全相同候選日期與事件上加入20日同時段RVOL、突破量、回踩量縮及當根價格反應。
3. Delta／CVD／五檔只在Shioaji唯讀逐事件資料通過驗證後加入；現在不以代理量冒充。
4. 波動、籌碼、選擇權與跨市場只作後續環境增量；未通過共同事件配對前權重維持0。

## 防偷看與資料切割

- 以完整交易日為最小切割單位，禁止隨機拆分相鄰K棒。
- 特徵只可使用當時或更早已完成資料；未來標籤與特徵分檔保存。
- RVOL只使用目標日前資料；門檻只在訓練折估計。
- 正式120日最低規劃：前20日暖機、60日開發、20日驗證、20日封存留出；其後另累積至少30日前向交易日。
- 正向、反向、無效、樣本不足與失敗結果全部保存，不得刪除不漂亮結果。

## 升級門檻

- 目前29日只驗收可重現、缺值語意、時段／換月、防前視、同棒雙觸及成本計算；不得宣稱策略有效。
- 正式候選至少120完整日，樣本外成本後期望須為正、PF須大於1，且不得由少數極端獲利主導。
- 16點壓力成本下不得結構性失效；多／空、日／夜、市場狀態分開報告。
- 一般量能層必須在相同日期與相同候選事件下優於price-only，否則權重為0。
- 正式前向至少30交易日且60至100個獨立候選；未通過則退回研究，不進模擬委託。

## 目前樣本限制

2026-06-05至2026-07-17共有29個通過稽核的完整交易日；20日RVOL暖機後只有最後9日具完整基準。K棒列數不是獨立樣本數，無法支撐36個策略／方向／時段／期限格的正式比較。距120日最低門檻尚差91日。
