# V3.6.1 內資法人資料層

## 本階段決策

先收集與驗證資料，不做外資、大額交易人或多條件交叉比較，也不加入首頁評分。

## 可公開辨識的內資口徑

- 投信現貨買賣超。
- 自營商現貨自行買賣。
- 自營商現貨避險。
- 投信臺股期貨成交多方、成交空方、成交淨額及未平倉多方、空方、淨額。
- 自營商臺股期貨成交多方、成交空方、成交淨額及未平倉多方、空方、淨額。

政府基金、壽險、銀行與其他國內機構無法由公開資料逐家拆分，不會用「特定法人」代替，因為特定法人也包含外資。

## 更新方式

- 歷史回補使用期交所三大法人期貨契約下載。
- 最新資料優先使用期交所 OpenAPI。
- 原始月檔以 gzip 快取並保存 SHA-256、下載時間及匯入筆數。
- 日後 live snapshot 會同步投信與自營商多方、空方及淨部位。

## 下一階段輸入規格（尚未執行研究）

1. 投信現貨 1／3／5／20 日累積。
2. 自營商自行與避險分開的 1／3／5／20 日累積。
3. 投信與自營商期貨 OI 淨額、單日及五日變化。
4. 期貨多單變化與空單變化分開，避免淨額掩蓋雙邊同時擴張。
5. 結算與轉倉日標記。
6. 缺漏率與實際盤後可取得時間。

以上資料完成品質門檻後，才與外資、前五／前十、特法、價格、總 OI、選擇權及市場狀態做增量比較。
