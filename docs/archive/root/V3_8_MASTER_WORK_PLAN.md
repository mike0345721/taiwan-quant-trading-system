## 一、我們要完成什麼

最終目標不是做出更多圖表，而是依序完成：

1. 建立可追溯且每天安全更新的資料系統。
2. 找到能辨識盤勢、方向候選與不交易環境的有效特徵。
3. 建立扣除手續費、交易稅與滑價後仍為正期望值的策略。
4. 讓系統依市場狀態選擇已驗證策略，失效時自動降級或停用。
5. 依歷史重播、前向紙上、模擬委託、極小實單的順序逐級驗證。

本專案對「聖杯」的定義是：

> 不是永遠猜對多空，而是知道何時有優勢、何時不交易、應承擔多少風險，以及何時承認策略失效。

## 三、整體改革方向

### 改革一：不再使用一個模糊總分回答所有問題

面板與策略分開輸出：

- 市場狀態：趨勢、震盪、高波動、低流動性。
- 方向候選：偏多、偏空、中性；不是勝率。
- 價格確認：VWAP、開盤區間、突破與量能是否成立。
- 執行品質：進場是否過晚、成本與滑價是否合理。
- 風險否決：資料異常、事件、過度追價、訊號衝突。
- 研究證據：想法、樣本內、樣本外、前向、模擬或實單等級。

### 改革二：首頁只顯示可行動的結論

首頁最後應顯示：

```text
市場狀態：震盪偏高波動
允許策略：假突破回歸
方向候選：中性
價格確認：未確認
量能確認：不足
觸發條件：重新站回VWAP且賣壓縮小
失效條件：再次跌破區間低點
成本後預估R：尚未達門檻
目前決策：不交易
資料品質：完整
研究證據：前向觀察中
```

完整原始資料、圖表與研究報告放在下方分頁，不擠在首頁。

### 改革三：自適應不等於盤中自行調參

- 使用凍結策略庫，不讓正式策略盤中重訓。
- 市場狀態只負責選擇適用策略或不交易。
- 新版本先作Challenger，通過樣本外與前向門檻才可取代Champion。
- 資料漂移、成本增加或近期績效失控時，只能降低曝險或停用，不能自動放寬規則。

## 四、正式納入的指標

### A. 第一層：價格與一般量能，現在可做

這一層是所有策略的基準：

- 5分鐘OHLCV。
- VWAP及斜率。
- 開盤15分鐘區間。
- 前日高低與收盤。
- 夜盤高低與日夜盤跳空。
- ATR、實現波動及價格距離VWAP。
- 突破、回測、假突破與逾時未延續。
- 同時段相對成交量：與過去20個交易日同一時段比較。
- 突破量、回檔量縮及大量成交後的價格反應。

### B. 第二層：盤中動能與市場微結構，接上Shioaji後做

先逐筆保存Tick與BidAsk事件，再彙整成1秒、5秒、30秒及1分鐘；不能只每5秒留一張快照。

正式候選指標：

- 主動買進量、主動賣出量。
- 30秒／1分鐘Delta。
- 日盤與夜盤分開重置的CVD。
- 價格與CVD背離。
- 標準化價格反應效率。
- 大量主動買進卻漲不動、主動賣出卻跌不動的吸收候選。
- 距離加權五檔Order Book Imbalance。
- 委託簿失衡持續時間。
- 被吃單後的補單速度與流動性恢復。
- Bid／Ask價差、深度及短線流動性風險。

這些指標只作突破確認、禁止追價與進場品質改善；沒有單獨下單權限。

### C. 第三層：籌碼、選擇權與總體環境

只使用在盤中決策前已公布的資料：

- 外資期貨1日及5日變化、外資多空單變化。
- 外資現貨、投信、自營商自行與避險。
- 前五大、前十大與特定法人集中度。
- 盤後市場OI、近月／全月份口徑及換月旗標。
- 期現貨基差、近遠月價差。
- Call／Put牆、牆位移動、牆上OI、Max Pain。
- ATM IV、Skew、近週／月選期限結構及IV－實現波動。
- 上市／上櫃廣度、漲跌停與權值股結構。
- 美國VIX、臺指VIX、Nasdaq、SOX、美元台幣及重大事件。

這一層只建立環境、風險、目標區及禁止交易條件；沒有通過增量檢驗前，方向權重維持0。

### D. 第四層：風險與執行指標

- 成本後淨期望值與每筆R。
- 勝率、平均獲利、平均虧損及PF。
- 最大回撤、MAE／MFE與最差尾端結果。
- 預估滑價、實際滑價及兩倍滑價壓力測試。
- 進場距離VWAP／ATR、最低報酬風險比及持有上限。
- 資料新鮮度、缺漏、延遲、斷線與來源品質。
- 每日停止線、連續虧損與Kill Switch；只在模擬階段啟用。

## 五、明確不採用或延後的項目

- 不用單次五檔委買／委賣總量直接決定多空。
- 不把掛單快速撤除直接稱為Spoofing或市場操縱。
- 不使用盤中OI觸發，除非未來取得並驗證可靠來源；目前只用盤後OI作環境。
- 不使用原始「漲跌點數÷主動成交量」；改成依波動、深度與同時段標準化的價格反應效率。
- 不把價格上漲、CVD下降直接解讀成空單回補。
- 不把Call／Put牆、Max Pain、基差正負或外資淨空單直接當下單訊號。
- 不以勝率、單次命中、單一月份PF或大量Tick列數宣稱有效。
- 不在V3.8保存券商憑證、送出委託或自動提高風險。

## 六、策略家族與研究目標

第一輪固定三個可解釋策略：

1. 開盤15分鐘區間突破。
2. VWAP同向回踩續走。
3. 開盤區間假突破後回歸。

多方與空方分開研究。主要預測目標：

- 30／60／120分鐘先到`+1.5R`或先到`-1R`。
- 扣除成本後的淨期望值。
- 突破成功、假突破及吸收後反轉。
- MAE／MFE與適合持有時間。
- 趨勢、震盪、高波動與不交易狀態。

## 七、正式研究順序

每一層使用相同日期與相同候選機會配對比較：

```text
價格-only
→ 價格＋一般量能
→ 價格＋Delta／CVD／五檔
→ 價格動能＋波動環境
→ 價格動能＋籌碼環境
→ 自適應策略選擇器
```

新增一個因子群時必須做消融；不能把高度相關因子重複投票。Tick樣本不能隨機拆分，必須依完整交易日做Walk-forward，避免把同一天相鄰事件同時放進訓練與測試。

## 九、升級與停止門檻

- 正式盤中研究至少需要120個完整交易日；30日只作工程與初步驗證。
- 訓練、驗證、最終留出與前向資料完全分離。
- 樣本外成本後期望值須為正，且不能由少數極端獲利主導。
- 兩倍滑價下不得出現明顯結構性失效。
- 正向、反向、無效、樣本不足及失敗結果全部保留。
- 前向不通過就退回研究；不因單次大賺升級。
- 找不到穩定優勢時，系統保持不交易，實單階段不啟動。
