# Shioaji API Key 輪替與疑似外洩處理

適用範圍：本專案的唯讀行情連線。這份流程不啟用委託、帳務或正式交易權限。

## 平時輪替

1. 關閉 `15_START_SHIOAJI_READONLY.bat` 視窗，先停止舊連線。
2. 開啟永豐 API 管理頁：<https://www.sinotrade.com.tw/newweb/PythonAPIKey/>
3. 建立新的行情專用 Key：
   - 只選行情／資料所需權限。
   - 不選交易、帳務或正式下單權限。
   - IP 白名單只在確認為固定 IP 時使用；浮動 IP 會造成無法登入。
4. Secret Key 只會顯示一次，請直接存入本機安全設定；不要貼到聊天、GitHub、截圖或筆記。
5. 使用本專案的本機設定工具替換 Key，再啟動唯讀行情。
6. 確認畫面顯示：
   - Shioaji 已連線。
   - `executionAuthorized=false`。
   - 訂單路由為 disabled。
   - IX0001 與 2330 有新的行情時間戳。
7. 回到 API 管理頁，停用或刪除舊 Key。若頁面用詞不同，選擇明確表示停用、刪除或撤銷的控制；不確定時先聯絡永豐客服，舊 Key 不可繼續使用。

## 懷疑外洩時

1. 立即關閉唯讀行情視窗，停止使用該 Key。
2. 到 API 管理頁停用／刪除／撤銷舊 Key。
3. 不要只修改本機檔案；只要秘密曾外洩，舊 Key 必須視為永久失效。
4. 檢查 GitHub、聊天、截圖、日誌及備份是否出現 Key 或 Secret；有出現就移除公開內容，但仍須更換 Key。
5. 建立全新的行情專用 Key，依「平時輪替」重新驗證。
6. 檢查 `data/live-events/audits/` 的事件稽核結果，以及異常登入或非預期連線。

## 絕對不要做

- 不把 API Key、Secret Key、CA 密碼或 `.pfx` 放進 GitHub。
- 不把秘密貼到聊天或傳送截圖。
- 不為了取得行情而開啟交易權限。
- 不在這個唯讀服務加入買進、賣出、撤單或平倉端點。

## 目前專案安全邊界

- 只監聽 `127.0.0.1`。
- 行情事件採每日檔案、append-only 與 SHA-256 雜湊鏈。
- 每日檢查竄改、重複、序號缺口、時間偏差與磁碟空間。
- `executionAuthorized=false`，沒有委託路由。
