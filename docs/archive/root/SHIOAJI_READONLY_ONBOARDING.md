# 永豐 Shioaji 唯讀行情接線清單

更新日期：2026-07-23

## 目前原則

- 第一階段只接行情，不接帳務、不接交易、不啟用正式委託。
- API Key 只勾選「行情／資料」；不要先勾選「交易」。
- 面板程序不保存 `SJ_API_KEY`、`SJ_SEC_KEY`、憑證或憑證密碼。
- Shioaji 在另一個本機程序登入，面板只接收經過白名單與格式驗證的市場事件。
- 所有輸出固定為 `executionAuthorized=false`。

## 使用者先完成

1. 確認證券戶已可正常登入永豐理財網。
2. 若目標包含台指期與選擇權交易，確認期貨戶也已開通。
3. 在永豐 API 管理頁建立一把「行情專用」API Key：
   - 權限只開「行情／資料」。
   - 不開「帳務」與「交易」。
   - 設定合理到期日。
   - 有固定公網 IP 時啟用 IP 限制。
4. Secret Key 只會顯示一次，保存至專案資料夾之外；不要貼到聊天、GitHub或面板 `.env`。
5. 證券與期貨 API 條款及測試必須分別完成。正式下單所需憑證目前先不接入本專案。

## 本機環境

目前已確認 Python 3.13 可用，但尚未安裝 Shioaji。

安裝後可在專案資料夾執行：

```text
npm run shioaji:check
```

檢查器只顯示「是否就緒」，不顯示任何金鑰內容。

## 第一輪行情驗收

1. 先訂閱台積電 `2330` 的 Tick 與 Bid/Ask，確認證券行情權限。
2. 再嘗試 TX 近月 Tick 與 Bid/Ask。
3. 期貨戶與期貨 API 簽署完成後，再加入 TXO 近週 ATM 上下各 10 檔。
4. 連續收集至少一個完整日盤與一個夜盤。
5. 驗證：
   - 交易所時間與本機接收時間。
   - 重複事件、漏包、倒序與斷線重連。
   - 日盤／夜盤歸屬。
   - TX 近月與換月。
   - 與券商畫面抽樣比對至少 100 根五分鐘 K。
6. 驗收通過前，首頁價格確認維持「未確認」。

## 暫時禁止

- 不將 API Key 或 Secret Key 傳給 Codex。
- 不把憑證放進 GitHub、ZIP或 `standalone-v1`。
- 不開交易權限。
- 不建立買進、賣出、撤單或平倉 API。
- 不以第一天行情直接調整評分權重或宣稱策略有效。
